# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public issues.

If you find a vulnerability, contact the maintainer privately:

- Email: <maintainer@example.com>

Include the affected version, reproduction steps, and potential impact in your report. The maintainer will acknowledge and respond as soon as possible.

## Handling process

1. Confirm the vulnerability and assess its impact.
2. Fix it privately and prepare a patch release.
3. Publish the fix before disclosing details publicly.
